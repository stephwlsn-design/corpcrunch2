Phase 0 — Stabilize (Days 1–30) START HERE

Goal: Trusted baselines and a clean index.

  1. Verify Google Search Console for https://www.corpcrunch.io and https://www.corpcrunch.ai (DNS or HTML tag)
  2. Submit sitemaps in both properties: /sitemap.xml — confirm URL count (~300+) and Status = Success
  3. Export Coverage + Page indexing reports (CSV). Save baseline: indexed, discovered-not-indexed, excluded
  4. Confirm GA4 receives organic traffic for both hosts; create weekly Organic Landing Pages exploration
  5. Run PageSpeed / CWV on home + 1 article + /intelligent (mobile). Log LCP, INP, CLS
  6. Spot-check 10 public URLs: robots index/follow, canonical, OG image, JSON-LD present (View Source)
  7. Admin: open 1 PR draft → confirm SEO autofill → publish 1 polished article as dry-run of pipeline
  8. Assign owners (SEO/Growth, Editorial, Eng) — share this playbook and Phase 0 deadline (30 days)

Phase 0 exit criteria: Both domains verified; sitemaps Success; baselines saved; mobile LCP issues listed with owners; one end-to-end PR draft → SEO → publish dry-run complete.

Phase 1 — Indexation & topical spine (Months 1–3)

Step 1 — News & crawl infrastructure Week 1–2

  1. Eng: add Google News sitemap (articles < 48h) at /news-sitemap.xml and link from robots.txt
  2. Growth: create Google Publisher Center / News publication for Corp Crunch; submit site
  3. Eng: confirm Indexing API or ping path for new publishes (optional but preferred)

Done when: News sitemap returns 200; GSC shows it; test article appears as eligible.

Step 2 — Rebuild category hubs Week 2–4

  1. Pick 6 priority hubs: technology, finance, sustainability, ai-innovation, fintech-growth, market-analysis
  2. Editorial: write 150–300 word hub intro (what this desk covers + who it’s for)
  3. Eng: hub template = intro + top stories + related companies + FAQ schema block
  4. Growth: target 1 primary keyword + 3 supporting per hub; track in sheet

Done when: all 6 hubs live with unique meta + internal links to ≥5 articles each.

Step 3 — Publish machine Week 3–6

  1. Editorial calendar: ≥5 pieces/week (mix: news analysis, explainers, PR-sourced)
  2. For every draft: use admin SEO autofill → human edit meta title/desc → featured image 1200×630 → Publish Public
  3. Checklist before publish: slug clean, category set, alt text, OG image, allow index/follow ON
  4. After publish: URL Inspection → Request indexing for pillar pieces only (not every post)

Done when: 70%+ of drafts that leave admin have complete SEO fields; weekly cadence held 4 weeks.

Step 4 — Internal linking pass Week 5–8

  1. Eng: related-articles block from tags/category on article pages
  2. Editorial: every new article links to hub + 2 related articles in body
  3. Growth: orphan URL audit from GSC; fix or noindex thin pages

Done when: sample of 20 new URLs reachable ≤3 clicks from home.
